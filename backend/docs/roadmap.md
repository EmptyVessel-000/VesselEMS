# Worklist 项目 Roadmap

## 1. 目标与范围

### 1.1 终极目标（愿景）
- 构建面向短期业务的轻量级协作平台，服务委托方、服务方、管理者 3 类用户。
- 实现任务、文件、客户需求、分配、审批、统计等完整业务流。
- 支持容器化部署、低门槛使用、模块化扩展。

### 1.2 当前 Demo 目标（实验）
- 技术检验：Spring Boot + Vue 3 + Docker + PostgreSQL 基本堆栈可行。
- 基础任务模型：CRUD、状态滑块、剩余时间、API 通信、前端交互。
- 目的为尽快确定方案与代码结构，后续迭代逐步填功能。

## 2. 差距分析（Goal-Gap）

| 终极需求 | 当前 Demo | Gap | 备注 |
|---|---|---|---|
| 角色分离（委托/服务/管理） | 单一任务界面 | 有 | 设计权限和多级视图 |
| 文件上传 + 命名规范 | 无 | 有 | 需加附件管理模块 |
| 客户任务验收与反馈 | 无 | 有 | 加状态流与评论 |
| 用户认证/权限控制 | 无 | 有 | 需安全框架（Spring Security） |
| 统计/导出/结算 | 无 | 有 | 增加报表模块 |
| 自动/手动任务分配 | 仅手动改状态 | 有 | 可新增规则引擎 |

## 3. 迭代计划

### MVP 1（目前已实现）
- 任务列表、CRUD
- 任务状态（1-5）
- 过期提醒、剩余时间
- 后端基础 API、前端交互
- Docker 部署基础

### MVP 2（近期目标）
- 用户认证（登录、角色）
- 任务分配（领取、指派、转单）
- 基本看板视图（按状态/人员）
- api 级权限控制
- 文档说明：`instructions.md` + `roadmap.md`

### MVP 3（中期目标）
- 文件附件（上传、下载、命名规范提示）
- 客户验收流程（待验收、确认/驳回）
- 业务规则（客户/服务费/结算）
- 统计页（完成量、工时、收入）
- 任务模板、规范设置

### MVP 4（长期目标）
- 自动分配算法（策略、负载均衡）
- 跨项目/多团队支持
- 多语言/多租户
- 移动端适配
- 监控与报警（日志、性能、邮件）

## 4. 可行性与风险

- 技术可行：当前架构适合迭代；可接入成熟组件（Spring Security、Swagger、Flyway）。
- 经济可行：低成本，适合小微团队部署。
- 社会可行：契合零工经济、短期协作趋势。

风险控制：
- 明确 MVP 范围，禁止需求膨胀。 
- 先做核心流程，再补高级特性。 
- 保持单元/集成测试覆盖，及时修复漏洞。
