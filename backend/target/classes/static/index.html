📋 项目简介

Worklist 是一个基于 Spring Boot + Vue.js 的现代化任务管理系统。 它实现了完整的权限分离架构，支持三个不同角色（Guest、Member、Manager）的协作工作流， 提供任务创建、分配、执行、验收的全流程管理，以及详细的统计分析功能。

✨ 核心功能

📝

任务管理

创建、编辑、分配、跟踪任务，支持详细的任务描述和批注

👥

权限分离

三角色权限模型，确保不同用户只能访问相应的功能和数据

📊

统计分析

实时任务统计、打回率分析、成员绩效评估、七日趋势图表

✅

验收流程

完整的任务验收机制，支持通过、打回和重新分配

⚡

高效查询

使用 JOIN 查询一次性获取所有数据，消除 N+1 问题

🔒

安全认证

基于 Spring Security 的完整认证和授权机制

👤 角色说明

🎯 Guest（甲方）

  • 创建任务
  • 编辑未分配的任务
  • 审核任务验收
  • 通过或打回任务
  • 查看创建的任务统计

💼 Member（乙方执行）

  • 接受分配的任务
  • 更新任务进度
  • 提交任务验收
  • 接受打回的任务
  • 查看个人绩效统计

⚙️ Manager（乙方协调）

  • 分配任务给 Member
  • 管理所有任务
  • 查看全局统计
  • 分析成员绩效
  • 协调项目进度

🚀 快速开始

1. 创建账户
点击"创建账户"按钮，选择角色（Guest、Member 或 Manager）并填写信息。

2. 登录系统
使用创建的账户登录，进入对应角色的控制台。

3. 开始使用
根据你的角色，创建任务、分配任务或执行任务。

4. 查看统计
在统计页面查看任务进度、成员绩效和各类数据分析。

📈 任务状态流转

1 → 未分配 → 2 → 未开始 → 3 → 进行中 → 4 → 验收中 → 6 → 已完成

如果验收不通过，任务会进入 5 → 已打回 状态， 然后重新分配给 Member 继续执行。
