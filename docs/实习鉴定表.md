# 西安石油大学 校内学生实习鉴定表

## 一、实习内容

本次实习为校内专业实习，担任VesselEMS企业管理系统项目负责人，统筹全队开发进度与技术选型，独立完成后端核心功能开发。项目涵盖EMS基础框架、NL2SQL、RAG知识库问答三大模块。

EMS基础框架方面：采用Spring Boot+Java 21+PostgreSQL技术栈，设计前后端分离RESTful架构；独立设计18张数据库表，涵盖用户、角色、菜单、权限、部门等核心实体；搭建RBAC权限模型，设计33个细粒度权限码，实现JWT无状态认证与URL模式匹配的接口安全管控；自定义@OperateLog注解，通过AOP切面实现操作日志审计；独立完成12个Controller、50余个REST API端点开发，覆盖用户管理、角色管理、菜单管理、部门管理、系统配置、数据源管理、模型管理等全部业务模块。

NL2SQL模块方面：主导后端接口方案设计，带领组内同学完成接口开发，把关SQL安全检测与LLM调用方案。

RAG模块方面：主导后端接口方案设计，带领组内同学完成接口开发与联调，把关RAG问答技术方案。编写全套技术文档，使用Git管理版本，配合前端联调，参与项目答辩与资料归档。

## 二、个人小结

本次校内专业实习，是将课堂后端开发理论落地为工程实践的重要过程。作为项目负责人，我统筹全队开发进度与技术选型，独立完成EMS基础框架从系统架构设计、数据库建模、权限体系搭建到50余个REST API开发的全链路工作，并主导NL2SQL和RAG两个AI模块的后端方案设计与技术把关。

通过本次实训，我深入掌握了Spring Boot框架核心机制，包括Spring Security认证授权、JWT无状态令牌、JPA多表关联与事务管理、AOP面向切面编程等关键技术。实训强调AI辅助开发，我充分发挥对AI技术的理解与把控能力，带领团队利用大模型API、向量检索、文档解析等前沿技术攻克多个核心难题，在技术选型与方案评审中严格把关，确保项目技术路线合理可行。数据库层面，独立设计18张业务表的关联关系，掌握了PostgreSQL与MySQL双数据库兼容的工程实践。

实训期间，严格遵守代码规范与Git版本管理流程，养成了"设计先行、编码在后"的开发习惯。面对权限系统多对多关联计算等技术难题，主动查阅资料，逐步形成独立分析问题、分步解决的技术思维。在统筹团队开发过程中，锻炼了任务分解、进度把控与跨端联调协调能力。

同时我也认识到自身存在不足：对于框架底层原理、高并发处理等内容掌握较为浅显，复杂业务的抽象设计能力仍需加强。本次实习为我积累了宝贵的项目实战经验，后续我会结合实训暴露的短板继续查漏补缺，夯实后端专业基础，提升综合专业水平，为今后就业与深造打好基础。
